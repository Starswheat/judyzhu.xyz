# Archived prototypes

These files preserve earlier design work. They are not part of the Vite application or the published site.

- `early-homepage/` contains the earlier homepage’s JSX sections, styles, pond animation, and tweak controls. These are historical source fragments, not a standalone runnable application.
- `assets/icons/` contains earlier icon studies and their prompts.
- [Historical notes](../docs/archive/) contain prior design plans, QA, and bakery migration evidence.

Use [`src/`](../src/) for the current portfolio and [`public/`](../public/) for preserved pages that still have public URLs. Current setup and publishing instructions are in the [main README](../README.md).
